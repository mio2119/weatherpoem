# T11 目标用户与内容人工验收执行包

状态：**材料已准备，H1 未开始、未签收**。本文件把执行方案 T11 变成主持人可操作的任务，不是受试者记录、内容审校结果或项目方批准。使用 [空白任务记录](./templates/T11_user_tasks_template.csv)、[三日接触记录](./templates/T11_daily_exposure_template.csv) 和 [18 首内容审校表](./templates/T11_content_review_template.csv)。18 首的选择理由和当前来源字段见 [T08 待核样本](./T08_content_sample_2026-10-12.md)。

## 进入条件和资料边界

1. 项目方确认本次仅是 **6–8 名大学生的小范围可用性/审美验收**，不是现有 30–50 人、28 天校园试点；招募、告知、记录、退出、保留和删除方式须先由真实负责人确认。只招募已满 18 周岁、自愿参加的人，不因退出产生不利影响。
2. 固定本轮源码提交、可见 Windows 候选 EXE SHA-256、内容版本、设备/缩放和测试日期。若关键 UI、内容或候选哈希改变，标明变更前后记录，不能合并成同一版的成功率。
3. 在专用资料或明确隔离的账户中运行；不得把研究者的天气演练说成参与者当地实况。真实预警、撤回、资料故障不通过操纵参与者真实资料制造。发现安全或内容严重问题，先停止展示并按现有撤回流程处置。
4. 原始观察表复制到 `review/redesign/h1-private/` 或项目方指定的受控位置填写；该目录被 Git 忽略。仓库里只保留空白模板和不含可识别个人信息的汇总结论。联系信息、姓名、学号、录屏与原话不得进入 Git。跨日匹配仅用研究者分配的随机研究代码，映射关系由真实负责人单独保管、按告知期限删除；不要写进应用试点聚合数据。
5. 若项目方尚未批准记录或候选未稳定，可以检查模板，但不得开展真实招募，也不得将 H1 改为通过。

## 第一天：无讲解核心任务

主持人逐条读出任务目的，不提示按钮位置或操作方法。观察首次尝试；若参与者请求帮助，先记录卡点与原话，再提供最少帮助并继续，但该任务记为“非无提示完成”。每项记录是否尝试、是否无提示完成、帮助内容、卡点、参与者原话及候选哈希；不要用“看起来会用”替代实际操作。

| 任务 | 给参与者的话 | 无提示完成的可观察结果 |
|---|---|---|
| C01 首次设置 | “把应用设置到你愿意日常使用的城市和显示方式，然后开始。” | 明确知道最终城市；独立完成设置；不支持城市时不会误以为系统选中了它。 |
| C02 十秒读诗 | “先看十秒，请说出你看到了哪句诗、作者或题名，以及第一眼注意到什么。” | 能读出完整可见节选并找到题名/作者；记录是否忽略诗句而先看动效。 |
| C03 解释推荐 | “你觉得今天为什么推荐它？哪里让你相信或不相信这个理由？” | 能找到推荐理由，正确区分节日、真实天气、缓存/离线或节气；误认实况须记问题。 |
| C04 展开全文 | “请看完整作品，找到它的出处，再回到刚才的小诗笺。” | 独立进入全文、找到来源并返回来处；作品与收藏状态不变。 |
| C05 找到注释 | “有不理解的词句时，请找解释，再继续读。” | 独立找到至少一处注释或明确发现没有注释；不需主持人指出入口。 |
| C06 收藏复访 | “保存这首诗，离开阅读页，再找到并重新打开它；最后取消收藏。” | 收藏、复访、再读、取消的状态一致；不通过设置页迷路。 |
| C07 排版字号 | “试试从上往下读诗，再调整到舒服的字号；告诉我你更愿意用哪种。” | 独立切换横/竖排和字号，文本没有丢失，操作与返回仍可达。 |
| C08 收起找回 | “暂时收起它，过一会儿再找回来。” | 独立从托盘或已设计入口找回，不误以为应用已退出；自动弹出是否打断其他任务另记。 |

## 第二、第三个不同自然日：重复接触

必须是同一参与者至少三个**不同的当地自然日**，不通过快进系统时钟或连续看三张截图替代。每天记录：候选哈希、日期、实际诗笺/诗境、是否主动阅读或直接忽略、是否收起、是否关闭动效、是否被学习/工作打断、1–5 级的分心与视觉疲劳自评，以及造成判断的原话。量表只帮助追问，不能用平均分代替具体行为和原因。参与者可随时停止使用或退出。

静态与轻动效、横排与竖排的对照应尽量使用**同一首诗、同一字体与尺寸、相同背景亮度**；记录展示顺序，避免只把先看到的版本当作偏好。对照画面若为隔离演练，需明示；真实三日接触与演示图的结论分开。观察是否持续盯着背景而非读字、是否主动关闭动画、是否因空间拥挤回到横排。发现高影响的持续分心或疲劳，提出更弱动效/静态或布局修改并用相同任务复测，不凭首日新鲜感签收。

## 18 首具名内容审校

审核者逐首对照可靠底本或可核查页面，填写具体版本/链接与卷次或定位、原文异文判断、注释、时代背景、“放进今天”的表述、节日/天气/节气标签是否准确。现有 `sourceVerified` 仅是工程初审，不能预填本轮审校为通过。来源只写《全唐诗》等总集时，不能由 AI 猜造卷次和版本。问题分为阻断发布、需修订、说明即可；有修订时记录内容提交与第二次具名复核。审核人、日期、依据和结论缺一项，单首保持待核。

## 汇总与 H1 判定

- 对 C01–C08 分别列出“无提示完成数/实际尝试数”，并计算全部核心任务的总分子/总分母；计划门槛为至少 **80% 无提示完成**。缺席或环境阻断要单列原因，不能静默删去失败尝试或只报百分比。严重的错误城市、不实天气、无法返回/找回、文字遮挡或安全提醒被弱化，即使总比例够也不能直接签收。
- 保留每个参与者在三个自然日的具体分心、视觉疲劳、关闭动效和收起原因，区分首日新鲜感与重复使用。审美意见相左时保留各方意见，由项目方写明取舍与复测结果。
- 18 首内容各有具名依据与结论；待核、问题未修复或仅 AI 自评均不能算通过。
- 项目方最后写明版本、参与人数、核心任务分子/分母、重大问题、修订与复测、内容审校状态，以及本次小范围试用的 Go/No-Go、签署人和日期。H1 通过不等于校园试点或公开发布就绪；后两者继续受独立门禁约束。
