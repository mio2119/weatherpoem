# WeatherPoem 候选版非开发人员 UAT

状态：执行计划已就绪，尚未由真实测试者执行。

## 执行对象

- 两名没有参与 WeatherPoem 开发的测试者；
- 使用专用或干净 Windows 账号；
- 测试当前发布清单中的 portable、NSIS 和 MSI 三项产物；
- 测试者必须自己阅读说明、安装和完成操作，开发人员只能观察和记录阻断点。

权威场景和当前发布物哈希位于
`review/release-candidate-uat-plan.json`，使用
`npm run uat:plan:check` 检查是否仍绑定当前候选。

## 必做场景

1. 理解未签名受控试用提示；
2. 自助完成 NSIS 干净安装；
3. 完成首次城市与开机启动选择；
4. 查看诗笺和延伸阅读；
5. 完成收藏、不贴合与每日换一首；
6. 断网后仍能使用本地规则；
7. 关闭到托盘并重新打开；
8. 启用和关闭开机启动偏好；
9. 清除个人数据并核对范围；
10. NSIS 卸载后程序被移除且用户数据未被静默删除；
11. 由获批管理员观察 MSI 安装、修复和卸载。

每项必须留下计划所列截图、日志或测试者说明。发现问题按 P0—P3 分级；只有
未接受的 P0/P1 为 0 才能建议进入试点。任何例外都必须包含缺陷编号、影响、
绕行方法、责任人、期限和批准人。

完成后把两名测试者、执行时间、证据文件、P0/P1 统计和质量/试点负责人决定写入
`review/evidence/RQT-17-defect-signoff-installer-uat.json`。计划文件本身不能
作为通过证据。
