## 不能提前开始

只有 `campus-pilot` 的 18 项门禁全部为 `passed` 才能招募。当前执行包会读取
`output/WeatherPoem_0.2.0_READINESS.json`，只要仍有阻断项，`goAllowed` 就必须
保持 `false`。人数少、内部关系熟悉或“先试试看”都不能绕过内容、隐私、设备、

- 自愿参与，可随时退出并清除本地记录；
- 不要求已有传统文化兴趣；
- 使用冻结的应用、内容和规则版本；
- 除 P0 安全、事实或隐私修复外不在试点中改变规则；确需变更时分版本报告。

## 九项成功标准

| 指标 | 门槛 | 主要证据 |
| --- | ---: | --- |
| 内容成功送达 | ≥95% | 本地匿名摘要 |
| 同日重复自动弹出 | 0 | 每周回访与缺陷日志 |
| 原文、作者、篇名、出处错误 | 0 | 内容纠错与缺陷日志 |
| “与今天不相关” | <10% | 本地匿名摘要 |
| “了解更多” | ≥15% | 本地匿名摘要 |
| 四周后仍保留应用和开机启动 | ≥40% | 最终设备检查与问卷 |
| 认为“不明显打扰” | ≥85% | 结束问卷 |
| 严重预警不当推荐 | 0 | 预警与事故日志 |
| 崩溃无感会话 | ≥99.5% | 待批准的本地会话聚合摘要 |

所有比例必须同时发布分子、分母、缺失数和退出数；分母为零时只能是 `null`，
不能写成 0%。既要给出合并口径，也要给出参与者层面的分布；不同版本不能直接
合并，门槛不能在看到结果后修改。

## 当前明确的测量批准缺口

客户端 v2 已实现无标识、无时间戳的已结束会话数、异常中断会话数与当前打开标记。
正常托盘退出会先落盘正常结束；进程被强制终止或崩溃时，下一次启动会把上次打开
标记保守计为异常中断。当前未结束会话不进入分母。

正式冻结试点版前仍必须：

1. 由隐私负责人具名批准 v2 口径和重新同意文本；
2. 由质量负责人在冻结候选上验证正常退出不误报、强制终止能在下次启动计入、
   当前会话不进入分母，并记录系统关机等保守误报边界；
3. 确认参与者仅主动复制聚合摘要，仍无自动上传、时间点、设备标识和崩溃转储。

批准和真机证据完成前，`measurementReady` 仍为 `false`，九项指标不能声称全部
可测。

## 六个阶段

1. 试点前：全部门禁、版本冻结、招募、同意、退出和应急演示；
2. 第 1 周：安装、自启、送达、重复弹出、崩溃和打扰；
3. 第 2 周：贴合、深入阅读、不贴合和天气安全；
4. 第 3 周：重复、视觉疲劳、自启保留和收藏；
5. 第 4 周：摘要、问卷、最终设备检查与 6—10 人访谈；
6. 试点后：删除记录、汇总指标/缺陷/内容错误并召开 Go/No-Go。

严重预警不当推荐、隐私泄露、广泛无法启动或数据破坏立即暂停；事实错误扩散、
重复抢焦点、崩溃集中或退出/清除失效则冻结招募和版本，由负责人在 24 小时内
决定修复、撤回或终止。
