# WeatherPoem 内容维护与发布流程

当前 MVP 不建设内容后台，诗词内容随 Git 版本管理，并通过内容数据与审核记录完成录入、校验和发布分离：

- `src/data/poems.ts`：首批作品与正式目录入口
- `src/data/poems-expanded-a.ts`、`poems-expanded-b.ts`：扩充作品的正文、来源、说明和情境标签
- `src/data/content-reviews.ts`：草稿、审核、发布、撤回状态

## 状态

| 状态 | 能否进入推荐 | 用途 |
| --- | --- | --- |
| `draft` | 否 | 正在录入或补充来源 |
| `reviewed` | 否 | 已完成初审，等待发布确认 |
| `published` | 是 | 通过发布门禁后进入候选 |
| `retracted` | 否 | 发现错误、版权或表达风险后撤回 |

## 新增作品

1. 在对应内容分片增加作品，使用稳定且唯一的 `id`，并将新分片接入 `poems-expanded.ts`。
2. 在 `content-reviews.ts` 增加同一 `workId`，初始状态设为 `draft`。
3. 补齐篇名、作者、朝代、体裁、全文、首页摘句、来源、文化背景、当代连接和情境标签。
4. 内容初审后改为 `reviewed`，记录审核人、日期和备注。
5. 发布确认人核对来源与标签后，将状态改为 `published`，并设置 `sourceVerified: true`。
6. 执行：

```powershell
npm run content:check
npm run check
```

## 自动门禁

应用构建时会执行内容发布校验。以下情况会直接阻止发布目录生成：

- 作品 `id` 重复；
- 作品没有对应状态记录，或审核记录指向不存在作品；
- `published` 作品缺少篇名、作者、朝代、体裁、全文、摘句或来源；
- 首页摘句无法在全文中找到；
- 来源未核验，或缺少审核人、审核日期；
- 全文、摘句含空行，或作品没有完整词句注释；
- 一句概述、文化背景或当代连接的信息量低于最低门槛；
- 质量分超出 0—10；
- 没有任何节日、天气、节气或季节标签。

草稿、已审核未发布、已撤回作品不会进入推荐引擎。

目录测试还会阻止以下回退：

- 已发布作品少于 120 首；
- 传统八节、二十四节气、四季、四时段或主要天气没有候选；
- 作品标识或审核记录数量不一致。

## 具名专家复核包

工程门禁只能证明结构、字段和标签覆盖符合约束，不能代替权威底本逐字核对。项目为
当前 120 首发布目录提供单独的专家审核包：

- `review/content-review-catalog.json`：由当前发布目录机械生成的只读事实快照；
- `output/WeatherPoem_内容专家审核回收模板_2026.07.1.csv`：机器回收模板；
- `outputs/content-review-2026.07.1/WeatherPoem_内容专家审核工作簿_2026.07.1.xlsx`：
  专家填写工作簿。

每首作品需要填写具名初审人、所属机构、日期、权威底本版本、HTTPS 证据链接或
馆藏/书目编号，并分别判断正文、作者朝代体裁、来源与注释、当代连接表达和情境标签。
之后必须由另一名复核人填写最终结论。初审人与复核人不能是同一人。

内容发生变化后重新生成审核快照和 CSV 模板：

```powershell
npm run content:review:export
npm run content:review:check
```

专家完成 XLSX 后，将“逐首审核”工作表另存为 UTF-8 CSV，并执行：

```powershell
npm run content:review:validate -- D:\审核回传\WeatherPoem_逐首审核.csv
```

回收校验会锁定内容版本、作品数量、作品标识和 A—M 列的当前事实，拒绝缺失、增加、
重复或被直接修改的作品。只有 120 首均具备双人审核、底本证据、五项通过结论且没有
需修订或撤回项时，才会报告达到权威复核发布门禁。发现问题时应先修改源码、更新内容
版本并重新导出审核包，不得在工作簿中直接覆盖只读内容。

## 撤回

紧急停止传播时，先通过严格内容撤回清单追加作品 ID 并递增修订号。客户端会让该作品
立即退出候选、阅读页和收藏内容列表；如果它正是当日推荐，只显示“内容正在校正”。
断网继续使用最后有效清单，旧修订不能恢复已撤回内容。完整契约和演练见
`docs/CONTENT_CONTROL.md`。

随后把审核记录状态改为 `retracted` 并说明原因，更新内容版本、重新完成复核并构建
内容包。撤回不删除本地收藏标识、历史或反馈；标识保留，但正文不再展示。只有更正
内容重新通过双人审核后，才可用更高修订号解除撤回。

## 审核边界

当前 120 首内容属于 MVP 公版古典诗词内容包，已经通过结构、来源字段、标签覆盖
和发布状态的工程初审。`sourceVerified` 在当前阶段只表示来源字段经过初步核对，
不等同于使用权威点校本完成逐字复核。具名双人审核工作簿与机器回收门禁已经就绪，
但在真实审核人完成并回传之前，不得把当前内容描述为已经完成权威复核。
