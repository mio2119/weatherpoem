# WeatherPoem 官方预警网关契约

WeatherPoem 客户端不直接绑定某一家气象数据供应商。学校或运营方应在取得合法授权后，
部署一个 HTTPS 网关，把供应商或属地气象部门数据规范化为本契约。客户端仅信任配置的
单一网关地址，并继续保留 Open-Meteo 基础天气安全代理作为失败降级。

## 请求

构建时配置：

```text
VITE_WARNING_API_URL=https://warning.example.edu.cn/v1/active
VITE_WARNING_TIMEOUT_MS=2500
```

客户端发送 `GET` 请求：

```text
https://warning.example.edu.cn/v1/active?cityId=beijing&city=北京&province=北京
```

请求不包含经纬度、设备标识、账号、收藏、阅读历史或推荐记录。

## 响应

```json
{
  "cityId": "beijing",
  "warnings": [
    {
      "id": "bj-rain-20260724-001",
      "title": "暴雨黄色预警",
      "level": "warning",
      "description": "预计未来六小时部分地区将出现强降水。",
      "source": "北京市气象台",
      "area": "北京市",
      "publishedAt": "2026-07-23T23:30:00+08:00",
      "expiresAt": "2026-07-24T08:00:00+08:00"
    }
  ]
}
```

`level` 必须由网关规范化为：

- `advisory`：需要留意的较低等级预警；
- `warning`：需要调整出行或活动安排；
- `severe`：可能造成显著人身与财产风险。

客户端对任何有效的 `official` 记录暂停普通诗笺，不依据客户端自行翻译颜色等级。

## 客户端拒绝条件

- 响应 `cityId` 与请求城市不一致；
- `id`、标题、描述、发布机构、地区、发布时间或失效时间缺失；
- 地区不包含所选城市名或省级行政区名；
- 发布时间晚于客户端当前时间超过十分钟；
- 预警已经失效，或失效时间不晚于发布时间；
- 单条预警有效期超过七天；
- 等级不在允许集合内；
- 单次超过 20 条时，仅检查前 20 条；
- 正式环境使用非 HTTPS 地址。

网关超时、非 2xx、响应格式错误或任何一条记录不合格都不会中断基础天气。合格记录继续
展示，不合格记录被丢弃；完全不可用时使用 Open-Meteo 天气代码、风速和小时降水代理。

## 网关职责

客户端校验不能替代数据授权与服务端治理。部署方必须完成：

1. 与气象数据供应方签订授权并保存许可范围；
2. 保留原始发布机构、行政区、等级、发布时间、失效时间和撤销状态；
3. 对撤销、更新和同一预警多版本做幂等处理；
4. 以服务器时间过滤失效记录，并限制缓存不晚于供应方更新周期；
5. 记录可审计的供应方响应 ID，但不记录客户端设备或个人使用轨迹；
6. 配置速率限制、监控、降级告警和证书续期；
7. 将正式网关唯一 HTTPS 源加入 Tauri `connect-src`，不要放开通配域名。

## 验收

- 正常、无预警、超时、500、错城市、过期、未来时间、撤销和重复更新均有网关测试；
- 客户端在网关 2.5 秒内无响应时仍能进入基础天气流程；
- 有效官方预警显示发布机构、地区、发布时间和有效期；
- 任何有效官方预警出现时不展示诗词；
- 官方记录失效后不再从六小时天气缓存中展示；
- 抓包确认请求没有经纬度与用户行为数据；
- Windows 10/11 真实安装包完成断网与弱网测试。
