# WeatherPoem 试点范围冻结提案

状态：安全默认提案已形成，等待项目发起人具名批准。

## 当前建议

- 候选版本：WeatherPoem 0.2.0，内容与规则版本 2026.07.1；
- 当前只允许内部展示和受控内部测试，不允许公开下载；
- 校园试点在其余必需门禁关闭后进行，范围为 30—50 名年满 18 周岁的
  Windows x64 用户，记录周期 28 天；
- 天气使用 Open-Meteo、缓存和离线规则降级；
- AI 理由保持本地规则模式，付费 AI 和其他付费服务月预算暂定为 0；
- 官方预警在取得数据授权、部署 HTTPS 网关并收窄 CSP 前关闭；
- 试点统计只做单独同意后的本地日聚合和人工导出，不自动上传；
- 二进制通过手动安装上一批准版本回滚；内容使用撤回清单或全局暂停；
- 在线增强出现问题时关闭端点并回退本地规则。

机器权威提案位于 `review/scope-freeze-proposal.json`。它绑定当前发布清单和
EXE SHA-256，`npm run scope:freeze:check` 会拒绝公开分发、默认付费 AI、虚构
责任人或虚构批准。

## 发起人需要补齐

1. 为项目发起、试点、发布、回滚、内容、安全隐私和质量角色指定真实姓名；
2. 确认“付费服务预算为 0”，或给出预算上限、预算负责人和关闭阈值；
3. 接受或修改当前 AI、官方预警、统计与分发范围；
4. 召开 Go/No-Go，并把决定、时间和证据写入
   `review/evidence/RQT-18-scope-ai-version-freeze.json`。

在具名记录通过人工证据契约前，RQT-18 只能保持 `partial`，不能开始校园招募，
也不能公开分发。
