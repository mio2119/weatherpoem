# WeatherPoem 无障碍实现与真实系统验收

## 1. 当前结论

`2026.07-accessibility-v1` 已完成可自动检查的实现基线：

- 页面切换后，焦点进入新页面的主区域，视觉顺序与键盘顺序一致；
- 图标按钮有可访问名称，诗名、作者、正文、来源和操作具有明确语义；
- 天气安全暂停使用文字、图标、标题和边框表达，不只依赖颜色；
- 浅色与深色关键普通文本配色达到至少 4.5:1；
- 支持 `forced-colors`、`prefers-contrast` 和系统/应用内减少动态；
- 移除了 360×560 固定最小视口，并为 300 CSS px 以下提供回流样式，
  避免 200% 缩放时把操作区裁到窗口外。

这不是人工无障碍验收。`review/accessibility-plan.json` 中五项真实系统测试保持
`pending`，在具名人员、真实安装版和证据存在前，`RQT-14` 必须保持
`partial`。

## 2. 自动基线

在项目目录执行：

```powershell
cd E:\weatherpoem
npm run accessibility:check
npm run test
```

自动检查会验证：

1. 进入页面后的焦点实现及测试存在；
2. 主路径组件具有可访问名称；
3. 关键文字配色的计算对比度不低于 4.5:1；
4. 高对比、减少动态和窄视口回流样式仍在；
5. 计划文件没有把未执行的真实辅助技术测试写成通过。

自动检查不能判断语音是否自然、WebView2 在真实对比度主题下是否完整绘制，也不能
证明 Windows 200% 文本大小下没有设备特有问题。

## 3. 真实安装版测试准备

- 使用待发布的 NSIS 或 MSI 安装版，不使用浏览器开发预览；
- 记录应用版本、安装包 SHA-256、Windows 版本、WebView2 版本、显示器与缩放；
- 从未配置状态开始，另准备已配置、至少收藏一首诗的状态；
- 测试普通诗笺、天气安全暂停和内容校正三种场景；
- 每项记录执行人、日期、结果、缺陷编号和截图/录屏或测试记录位置；
- 发现 P0/P1 问题时停止通过，不得仅在证据中写“已知限制”。

## 4. 仅键盘走查

不使用鼠标，按以下顺序完成：

1. 启动应用，确认焦点进入首次设置主区域；
2. 用 `Tab` / `Shift+Tab` 搜索并选择城市、切换开机显示、勾选同意；
3. 按 `Enter` 完成首次设置；
4. 在今日诗笺依次访问继续读、收藏、换一首和不太贴合；
5. 进入全文，确认返回与收藏都可操作；
6. 进入设置，修改主题与减少动态，打开收藏和校园试点，再返回；
7. 触发天气安全暂停，确认不会把焦点留在已经卸载的旧页面；
8. 检查每个焦点都清楚可见，没有键盘陷阱，顺序与画面一致。

通过条件：核心路径全部可完成；无焦点丢失、隐藏焦点、循环陷阱或只能用鼠标的
操作。

## 5. Windows 讲述人

1. 使用 `Win+Ctrl+Enter` 启动讲述人；
2. 从首次设置走到今日诗笺、全文、收藏、设置和安全暂停；
3. 确认页面切换时能听到新页面名称；
4. 确认诗名、朝代/体裁、作者、诗句、推荐理由、全文和文本来源按合理顺序朗读；
5. 确认收藏状态、禁用的“今日已换”、开关状态和天气警报可被识别；
6. 确认装饰印章、警报图标不会重复制造无意义语音。

通过条件：不看屏幕也能理解当前页面、内容层级、状态和可执行操作。

## 6. NVDA

用当前受支持的 NVDA 稳定版重复第 5 节路径，并额外检查：

- 标题快捷键能按页面结构移动；
- 地标导航可找到主区域；
- 表单模式下城市选择、复选框、开关和下拉框可操作；
- 警报在进入页面时被读出一次，不持续重复；
- 中文标点、朝代、作者和温度读法可以理解。

讲述人通过不能替代 NVDA；两者都必须留下独立结果。

## 7. Windows 对比度主题

在 Windows“设置 → 辅助功能 → 对比度主题”中启用一个系统主题，重新打开应用：

1. 检查顶栏、主卡片、正文、按钮、输入框、开关和焦点框；
2. 检查普通、悬停、选中、禁用和警报状态；
3. 确认边界没有因背景被系统替换而消失；
4. 确认天气安全暂停仍靠标题、图标形状、文字和边框表达；
5. 分别检查浅色、深色设置不会覆盖系统强制颜色。

通过条件：所有文字与控制仍可辨认，状态不只依赖原始品牌色。

## 8. 200% 文本与显示缩放

分别执行两轮：

1. Windows“设置 → 辅助功能 → 文本大小”设为 200%；
2. Windows“设置 → 系统 → 屏幕 → 缩放”设为 200%。

每轮重新启动应用，走完首次设置、主卡片、全文、设置、收藏、试点和安全暂停。
允许纵向滚动，不允许横向滚动成为完成任务的前提。确认：

- 标题、诗句、按钮文字和表单标签不被截断；
- 返回、窗口按钮和主操作始终可到达；
- 长诗名、长城市名、长预警文字和匿名摘要能够换行或滚动；
- 固定顶栏不会覆盖正文；
- 200% 下所有核心任务仍能完成。
